Simulador de risco de crédito

Informe os dados de uma proposta para ver a probabilidade de inadimplência estimada pelo modelo CredAIR.

Modelo de regressão logística treinado com 80% da base (ROC-AUC 0,781 no teste). O limiar de 0,31 foi escolhido para reduzir a aprovação de maus pagadores e deve ser revisto com os custos reais do negócio. Ferramenta de demonstração: não substitui uma política de crédito.
